# HCMC AI Challenge Rules Notes

This file should contain only rules or observations we have verified from
official pages, CodaLab/Codabench pages, or provided competition files.

## Verified From Prior Years

- 2024/2025 tasks are multimedia retrieval tasks, not generic chatbot tasks.
- 2025 preliminary Group A used TKIS, Q&A, and TRAKE.
- Prior submission formats used CSV rows with video/frame predictions.
- Ranking commonly rewards finding the correct answer near the top of up to 100
  rows.
- Last year's final workbook shows progressive reveal: one query can contain
  multiple clue batches.

## Not Confirmed For 2026

- exact dataset contents;
- exact query types;
- exact CSV/zip format;
- scoring tolerance;
- allowed APIs/cloud/internet;
- whether automatic agent mode is required;
- final-round visual prompt capture rules.

## Practical Rule For Implementation

Keep ingestion, validation, and export configurable until official 2026 rules are
published.
